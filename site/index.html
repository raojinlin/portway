代理命令，复制就好。

03 / 简单，也有边界

连接你的服务器。
配置留在你的机器。

复用已有的 SSH Host、私钥和跳板配置。普通 SSH 与 ProxyJump 由 Go 原生实现，不需要额外安装系统 ssh 命令。

默认严格校验服务器主机密钥。配置和日志保存在本机，不需要注册 Portway 账户。

还有几个小问题。

需要先装 Go、Node.js 或 SSH 吗？+

使用构建好的桌面应用不需要 Go 或 Node.js，普通 SSH 和 ProxyJump 也不依赖系统 ssh。自定义 ProxyCommand 可能仍需外部程序。Windows 需要 WebView2，Linux 需要 GTK3 和 WebKitGTK 4.1。

可以直接使用已有的 SSH config 吗？+

可以。在线路的 SSH 服务中填写 Host 别名，Portway 会读取 ~/.ssh/config，支持 IdentityFile、ProxyJump 和多级跳板。并非所有 OpenSSH 扩展都受支持，具体范围请查看项目文档。

没有桌面环境，也能用吗？+

可以使用 daemon，通过内嵌 Web 页面或 CLI 管理。Web / HTTP API 没有登录认证，默认只监听 127.0.0.1，请勿直接暴露到公网。CLI 不能控制桌面应用里的线路。

SOCKS5 会改变整个系统的代理吗？+

不会。复制的命令只影响当前终端内支持代理环境变量与 SOCKS5 的程序。当前支持 TCP CONNECT，不支持 UDP，也没有 SOCKS5 用户名密码认证，建议只监听回环地址。
