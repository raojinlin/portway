03 / MCP and agents

Connect Codex and other agents
through MCP.

After you enable MCP, agents can inspect tunnels and active connections. Portway permissions determine whether they can start, stop, edit, or delete tunnels.

01

Open MCP settings Choose read-only, inspect and control, or full management access; then configure token or OAuth authentication.

02

Connect your agent Copy the Codex, Claude Code, or generic client connection example from settings and authenticate with your chosen token or OAuth mode.

03

Install the Skill if needed The settings page provides a download and installation instructions for agents. The Skill explains Portway tools and their boundaries; it does not change MCP permissions.

MCP listens only on the local loopback address. MCP tools neither accept nor return SSH passwords; unauthorized actions are absent from the agent tool list.

04 / Authentication and data

Use your SSH configuration.
Keep data on your device.

Use Host aliases, private keys, and ProxyJump from your SSH config. Standard SSH and ProxyJump are implemented in Go, so the system ssh command is not required.

Server host keys are strictly verified by default. Tunnel settings and logs stay on your device; no account is required.

Frequently asked questions

Do I need Go, Node.js, or SSH installed?+

The packaged desktop app does not need Go or Node.js. Standard SSH and ProxyJump do not require the system ssh command. A custom ProxyCommand may still need an external program. Windows needs WebView2; Linux needs GTK3 and WebKitGTK 4.1.

Can I use my existing SSH config?+

Yes. Enter a Host alias as the tunnel SSH server. Portway reads ~/.ssh/config and supports IdentityFile, ProxyJump, and multiple hops. Some OpenSSH extensions are not supported.

Where can I run the web interface?+

Run it on a personal computer or server without a graphical desktop. Open the management page in a browser to inspect connections and configure or control tunnels.

Can an agent manage my tunnels?+

Enable MCP in Portway and connect the client to the local MCP service. The default “inspect and control” permission allows viewing, starting, and stopping tunnels; creating, editing, or deleting requires “full management.” The built-in Skill explains tool usage but does not change access.

Does SOCKS5 change the system proxy?+

No. The copied command only affects programs in the current terminal that support proxy environment variables and SOCKS5. Portway supports TCP CONNECT, not UDP or SOCKS5 username/password authentication; bind to loopback where possible.
