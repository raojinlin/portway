# Portway 落地页

独立的中文产品官网，不替换 `web/` 管理界面，也不连接运行中的 Portway 服务。HTML、CSS 和原生 JavaScript，无第三方字体、运行时依赖或外部统计脚本。

配色与 App 的 `web/src/index.css` 一致：灰白 / 深灰底、蓝色强调色。页头可选浅色、深色或跟随系统，默认跟随系统并实时响应系统主题变化；手动偏好保存在浏览器 `portway-site-theme` 中，不修改桌面应用设置。禁用 JavaScript 时仍通过 CSS 跟随系统。

## 预览

在仓库根目录运行 `make site`（需要 Node.js 20+），打开 <http://127.0.0.1:4173>。端口冲突时可用 `PORTWAY_SITE_PORT=4174 make site`。本地服务器只绑定回环地址，不开放后端或真实 SSH 连接。

## 页面内容

- 产品介绍和示例线路，可演示启停与连接详情。
- 桌面端与 Web 端的入口、部署位置和线路管理边界。
- 本地、远程、SOCKS5 三种转发说明，支持键盘切换。
- macOS 菜单栏网页演示：两行上传 / 下载速率、线路展开、启停、查看连接和复制代理。与首屏共用示例启停状态，停止后隐藏复制入口；不会控制真实系统菜单。
- 后台常驻、日志与代理命令。复制的是示例，不会执行命令或设置系统代理。
- 本机 MCP 与 Agent 使用步骤、权限范围和内置 Skill 的用途。
- 按当前系统预选安装说明，也可手动切换。
- 安装、SSH config 和安全边界的常见问题。

线路、连接和流量均为标注过的静态示例，不是真实截图或实时监控。文案只描述已实现的能力。页面不提供公开下载入口；安装包由项目维护者分发。

## 部署

将此目录中的 `index.html`、`style.css`、`theme.js`、`main.js` 和 `mark.svg` 原样部署到任意静态站点服务。无需构建，资源路径均为相对路径，支持部署在子目录。不需要部署本地预览服务器。

公开域名确定后，可添加 canonical URL、社交分享图及 sitemap。本次不包含自动部署，不改动现有桌面和 CLI 打包流程。
